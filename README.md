# PrimeStore

PrimeStore is a simple e-commerce frontend project built as a college assignment to practice and demonstrate my learning of:

- HTML
- CSS
- Tailwind CSS
- JavaScript

## Features

- Responsive modern UI
- Product slider/banner
- Dynamic product rendering using FakeStore API
- Product search and sorting
- Shopping cart functionality
- Balance system using localStorage
- Coupon discount system
- Review slider using local JSON data

## Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- FakeStore API

## Purpose

I built this project after learning the basics of frontend web development to improve my practical skills and understand how real-world interactive websites work.
